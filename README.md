# Android ToDo Testing

Dieses Projekt ist eine Android-basierte ToDo-Listen-Anwendung zur Untersuchung von Unit Tests und Instrumented Tests.

## Technologien

- Kotlin
- Jetpack Compose
- JUnit
- Compose UI Testing
- Android Emulator

## Funktionen

- Aufgabe hinzufügen
- Aufgabe löschen
- Aufgabe als erledigt markieren
- Validierung leerer Eingaben

## Tests

- Unit Tests für die Aufgabenvalidierung
- Instrumented UI Tests für Benutzerinteraktionen auf dem Emulator

## Forschungsfrage

Wie können Instrumented Tests für eine Android-basierte ToDo-Listen-Anwendung konzipiert und implementiert werden, und welche Testarten eignen sich dabei zur Sicherstellung der Softwarequalität?
